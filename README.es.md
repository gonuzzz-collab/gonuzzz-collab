# Patricio Castillo

**Arquitectura y gobernanza de sistemas asistidos por IA · Agentes · Soberanía de datos · Documentación viva**

[Read in English](README.md)

Trabajo en el diseño, evaluación y gobernanza de sistemas de software desarrollados con un uso intensivo de inteligencia artificial, con especial interés en mantener su evolución comprensible, verificable y bajo control humano.

**GoNucleo IA** es la identidad de trabajo de un laboratorio tecnológico independiente bajo el cual desarrollo proyectos, experimentos y productos en esta área.

**Sitio oficial:** https://gonucleo.cl

## Enfoque actual

- Arquitectura de software asistida por IA
- Gobernanza de agentes y supervisión humana
- Evidencia, trazabilidad y memoria de sistemas
- Documentación técnica viva
- Soberanía de datos y sistemas local-first
- Evolución de software controlada y revisable

## Trabajo seleccionado

### [Governor Agent](https://github.com/gonuzzz-collab/governor-agent)
Agente de gobernanza para cambios de software asistidos por IA, diseñado alrededor de autoridad explícita, políticas, evidencia y escalamiento humano controlado.  
**ALLOW · DENY · ESCALATE · Código abierto · Apache 2.0**

### [Living Memory](https://github.com/gonuzzz-collab/living-memory-public)
Memoria técnica local-first respaldada por evidencia para sistemas de software en evolución, con procedencia, procesamiento determinista, trazabilidad y autoridad humana.  
**Descripción pública · implementación propietaria · desarrollo activo del producto**

### [Lexidiam](https://github.com/gonuzzz-collab/lexidiam-public)
Plataforma profesional de transcripción y revisión diseñada alrededor de privacidad, soberanía de datos, custodia y validación humana.  
**Descripción pública · núcleo propietario**
